# MangaTrack

Веб-приложение для каталогизации, поиска и отслеживания манги, манхвы и маньхуа. 
Проект позволяет пользователям находить новые тайтлы, фильтровать их по множеству параметров, 
а также вести личные списки прочитанного и желаемого.

## Функционал

### 1. Каталог и поиск
Главная страница каталога выводит все доступные в базе тайтлы. Реализована **серверная фильтрация** (без перезагрузки страницы через JS, все параметры передаются GET-запросом), что позволяет сохранять ссылки на конкретные выборки.
*   **Поиск:** по названию манги и автору.
*   **Фильтр по типу:** манга, манхва, маньхуа (мультивыбор).
*   **Фильтр по жанрам:** логика «ИЛИ» (мультивыбор).
*   **Фильтр по году:** диапазон «от» и «до».
*   **Табы (Быстрые фильтры):**
    *   *Все истории* — базовая сортировка.
    *   *Популярное* — сортировка по убыванию рейтинга.
    *   *Новинки* — сортировка по дате добавления.
    *   *Выбор редакции* — тайтлы с рейтингом выше 8.5.

### 2. Карточка тайтла
При клике на мангу открывается её персональная страница. Отображается обложка, автор, жанры, год выпуска, количество томов, рейтинг и описание.

### 3. Личный кабинет и коллекции
*   **Авторизация и регистрация:** доступ к личным спискам открыт только авторизованным пользователям.
*   **Коллекция:** список тайтлов, которые пользователь собирает или уже прочитал.
*   **Вишлист:** список желаемых покупок/тайтлов.
*   **Добавление манги:** [Уточнить: любой пользователь или только админ?]

## Структура базы данных

База данных спроектирована с использованием реляционной модели и связей «многие-ко-многим».

*   **`manga`** — основная таблица с информацией о тайтлах (название, автор, рейтинг, год, обложка).
*   **`genres`** — справочник жанров.
*   **`manga_genres`** — связующая таблица для реализации связи «многие-ко-многим» между мангой и жанрами.
*   **`users`** — таблица пользователей системы (стандартная для Yii2).
*   **`user_manga`** — связующая таблица, хранящая связь пользователя с мангой (позволяет добавлять тайтлы в личные коллекции и вишлисты).
